PackBridge Documentation

PackBridge translates Shopify B2B order quantities into pack units your ERP, EDI, or warehouse system can consume. It is for merchants whose downstream systems expect cases, inners, pallets, or other operational units instead of raw eaches.

For a sample order, pack rule, signed webhook, and retry timeline, see the PackBridge demo.

Setup

  1. Install PackBridge from the Shopify App Store.
  2. Open PackBridge in Shopify Admin and confirm billing.
  3. Create pack-unit rules for the companies, locations, products, or variants that need translation.
  4. Add your outbound webhook endpoint in Settings.
  5. Place or replay a test B2B order and confirm the signed payload in your receiving system.

Shopify Permissions

PackBridge reads order, product, company, and location data needed to resolve pack-unit rules. It writes PackBridge-owned settings, jobs, and audit records in its own database. It does not rewrite Shopify orders unless a future release explicitly adds and documents that capability.

Pack-Unit Rules

Rules can map ordered quantities into operational units such as cases, inners, and pallets. Rules may be scoped by company, company location, product, or variant so B2B customers can keep different pack logic without changing storefront pricing.

Example

Input Shopify order line:

{ "sku": "SKU-CASE-12", "quantity": 24, "company": "Acme Wholesale" }

Output webhook payload:

{
  "orderId": "gid://shopify/Order/123",
  "lines": [
    { "sku": "SKU-CASE-12", "orderedEaches": 24, "packUnit": "case", "packQuantity": 2 }
  ]
}

Signed Webhooks

PackBridge signs outbound webhook payloads with an HMAC signature so your ERP/WMS endpoint can verify the message came from PackBridge and was not modified in transit. Keep the signing secret private and rotate it from Settings if your receiving endpoint changes ownership.

Retry Behavior

If webhook delivery fails, PackBridge records the failure on the job and retries according to the app's delivery policy. Failed and held jobs remain visible in the audit trail for review.

Billing

Launch pricing is $49/month with a 14-day trial for new installs. The $99/month PackBridge Monthly plan remains supported for existing or Pro customers.

Uninstall

Uninstall PackBridge from Shopify Admin. Shopify sends an uninstall webhook, and PackBridge stops processing new orders for that shop. Contact support if you need retained PackBridge job records removed earlier than the normal retention period.
