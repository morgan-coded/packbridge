Documentation / Demo

Translate Shopify B2B order lines into ERP-ready pack units.

This demo uses sample data to show how PackBridge reads a Shopify B2B order, applies merchant-owned pack rules, sends a signed payload, and keeps an audit trail. PackBridge does not rewrite Shopify order data in the current release.

1. Shopify B2B order line

Raw order quantity

A customer orders 24 eaches for a SKU that the warehouse fulfills as cases of 12.

{
  "orderId": "gid://shopify/Order/1001",
  "company": "Acme Wholesale",
  "location": "Dallas Distribution",
  "line": {
    "sku": "COFFEE-BAG-12PK",
    "quantity": 24
  }
}
2. Pack rule

Company and SKU-specific translation

The rule keeps storefront ordering simple while giving the ERP the pack unit it expects.

{
  "scope": "company_location + sku",
  "company": "Acme Wholesale",
  "location": "Dallas Distribution",
  "sku": "COFFEE-BAG-12PK",
  "unit": "case",
  "eachesPerUnit": 12,
  "deliveryMode": "signed_webhook"
}
3. ERP/WMS payload

Translated pack units

PackBridge preserves the original ordered eaches and adds the operational pack quantity for downstream systems.

{
  "orderId": "gid://shopify/Order/1001",
  "company": "Acme Wholesale",
  "lines": [
    {
      "sku": "COFFEE-BAG-12PK",
      "orderedEaches": 24,
      "packUnit": "case",
      "packQuantity": 2
    }
  ]
}
4. Signed webhook

Payload verification

Outbound requests include a timestamp and HMAC signature so the receiving endpoint can verify the source and detect payload changes.

POST /packbridge/orders
x-packbridge-timestamp: 2026-05-20T14:30:00Z
x-packbridge-signature: sha256=sample-signature-for-demo
content-type: application/json
5. Retry and audit trail

Operational evidence

  • 10:30 AM - Order received from Shopify.
  • 10:30 AM - Pack rule matched Acme Wholesale and COFFEE-BAG-12PK.
  • 10:31 AM - First webhook attempt timed out.
  • 10:33 AM - Retry delivered with a verified 200 response.
